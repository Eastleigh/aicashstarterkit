# 50 Plug-and-Play AI Prompts
## Copy, Paste, Profit

---

## How to Use These Prompts

1. Copy the prompt exactly as written
2. Replace the [BRACKETS] with your specific details
3. Paste into ChatGPT, Claude, or any AI tool
4. Edit the output to add your personal touch

---

## CONTENT CREATION (Prompts 1-10)

### 1. Blog Post Generator
```
Write a 1,500-word blog post about [TOPIC] for [TARGET AUDIENCE].
Include: an attention-grabbing intro, 5 actionable tips with examples,
and a conclusion with a call to action. Tone: conversational and
authoritative. Use short paragraphs and subheadings.
```

### 2. Listicle Creator
```
Create a "Top 15 [TOPIC]" article for [AUDIENCE]. For each item,
include: the name, a 2-sentence description, why it's useful, and
a pro tip. Rank them from good to best. End with a "How to Choose"
section.
```

### 3. Social Media Caption (Instagram)
```
Write 5 Instagram captions about [TOPIC] for a [NICHE] account.
Each caption should: start with a hook, include a story or tip,
end with a CTA, and include 5 relevant hashtags. Keep each under
150 words.
```

### 4. Twitter/X Thread
```
Write a viral Twitter thread (10 tweets) about [TOPIC]. Tweet 1
should be a bold hook. Tweets 2-9 should each share one insight
or tip. Tweet 10 should be a summary + CTA. Keep each tweet
under 280 characters. Use line breaks for readability.
```

### 5. LinkedIn Post
```
Write a LinkedIn post about [TOPIC] that positions me as an
expert in [INDUSTRY]. Start with a counterintuitive statement.
Share a personal story or observation. Include 3 actionable
takeaways. End with a question to drive engagement. 200-300 words.
```

### 6. YouTube Script
```
Write a 5-minute YouTube script about [TOPIC]. Include:
- Hook (first 15 seconds to grab attention)
- Problem statement
- 3-5 main points with examples
- B-roll suggestions in [brackets]
- CTA (subscribe + comment question)
Keep it conversational, not salesy.
```

### 7. Newsletter Email
```
Write a weekly newsletter email about [TOPIC] for [AUDIENCE].
Subject line options (give 3). Opening: personal anecdote.
Body: one big insight + 3 quick tips. CTA: [ACTION YOU WANT].
PS: tease next week's topic. Keep it under 400 words.
```

### 8. Podcast Show Notes
```
Write show notes for a podcast episode about [TOPIC] with
guest [NAME]. Include: a 3-sentence summary, 5 key takeaways
with timestamps, 3 memorable quotes, resources mentioned,
and a CTA to subscribe/review.
```

### 9. Content Calendar
```
Create a 30-day social media content calendar for a [NICHE]
brand. For each day, include: platform (rotate between Instagram,
LinkedIn, Twitter), content type (tip, story, question, behind-
the-scenes, tutorial), topic idea, and suggested hashtags.
```

### 10. SEO Blog Outline
```
Create an SEO-optimized blog outline for the keyword "[KEYWORD]".
Include: H1 title (with keyword), meta description (155 chars),
H2 and H3 subheadings, bullet points for each section,
internal/external link suggestions, and a FAQ section with
5 questions.
```

## COPYWRITING (Prompts 11-20)

### 11. Landing Page Copy
```
Write landing page copy for [PRODUCT/SERVICE] targeting
[AUDIENCE]. Include: headline (benefit-focused), subheadline,
3 pain points, solution description, 3 key features with
benefits, social proof placeholder, pricing section, FAQ
(5 questions), and CTA button text. Use the PAS framework.
```

### 12. Email Sales Sequence (5 emails)
```
Write a 5-email sales sequence for [PRODUCT] priced at [$PRICE]
targeting [AUDIENCE].
Email 1: Problem awareness + story
Email 2: Agitate the problem + introduce solution
Email 3: Social proof + case study
Email 4: Objection handling + FAQ
Email 5: Last chance + urgency + bonus
Subject lines for each. Keep emails under 300 words.
```

### 13. Facebook Ad Copy
```
Write 5 Facebook ad variations for [PRODUCT/SERVICE].
For each: headline (40 chars max), primary text (125 words max),
description (30 words), CTA button suggestion.
Mix styles: testimonial, problem-solution, curiosity,
benefit-focused, and urgency.
```

### 14. Google Ad Copy
```
Write 5 Google Search ad variations for the keyword "[KEYWORD]".
For each: 3 headlines (30 chars max each), 2 descriptions
(90 chars max each). Include the keyword naturally. Focus on
benefits and include a clear CTA.
```

### 15. Product Description
```
Write a compelling product description for [PRODUCT NAME].
Include: a hook headline, 3-sentence overview, 5 key features
(with benefits, not just features), ideal customer description,
and a "What's in the box" section. Tone: [BRAND TONE].
```

### 16. Case Study
```
Write a case study about how [CLIENT TYPE] achieved [RESULT]
using [PRODUCT/SERVICE]. Structure: Challenge (what they
struggled with), Solution (how they used the product), Results
(specific numbers), Quote (fictional testimonial). 500 words.
```

### 17. Press Release
```
Write a press release announcing [NEWS/LAUNCH]. Include:
headline, dateline, lead paragraph (who/what/when/where/why),
supporting details, quote from founder, boilerplate about
the company, media contact info placeholder. AP style. 400 words.
```

### 18. Testimonial Request Email
```
Write an email asking a customer for a testimonial for
[PRODUCT/SERVICE]. Be warm and specific. Include 3 guiding
questions they can answer. Offer to write it for them if they
provide bullet points. Keep it under 150 words.
```

### 19. Upsell/Cross-sell Email
```
Write an email to existing customers of [PRODUCT A] offering
[PRODUCT B]. Explain how B complements A. Include a special
"existing customer" discount. Use social proof. One clear CTA.
200 words max.
```

### 20. Abandoned Cart Email Sequence
```
Write 3 abandoned cart recovery emails for [STORE/PRODUCT].
Email 1 (1 hour later): Gentle reminder
Email 2 (24 hours): Social proof + address objection
Email 3 (72 hours): Discount/incentive + urgency
Subject lines for each. Under 150 words each.
```

## FREELANCING (Prompts 21-30)

### 21. Client Proposal
```
Write a freelance proposal for a [SERVICE TYPE] project.
Client needs: [DESCRIBE]. Include: understanding of their needs,
proposed approach (3 phases), timeline, deliverables list,
pricing (3 tiers: basic/standard/premium), and next steps.
Professional but warm tone.
```

### 22. Cold Outreach Email
```
Write a cold outreach email to [TYPE OF BUSINESS] offering
[SERVICE]. Keep it under 100 words. Start with a specific
compliment about their business. Identify one problem you
noticed. Offer a quick win. End with a low-commitment CTA
(15-min call, not "hire me").
```

### 23. Portfolio Case Study
```
Write a portfolio case study for my [SERVICE] work.
Project: [DESCRIBE]. Include: client overview, challenge,
my approach, key decisions made, results achieved, and client
testimonial (I'll fill in). Make it scannable with headers.
```

### 24. Rate Negotiation Email
```
Write an email to a client who wants to negotiate my rate of
[$RATE] for [SERVICE]. Politely hold firm on pricing. Explain
the value they get. Offer an alternative: reduced scope at
their budget, or payment plan. Stay professional. 150 words.
```

### 25. Project Scope Document
```
Create a project scope document for [PROJECT TYPE]. Include:
project overview, objectives, deliverables (specific list),
timeline with milestones, what's included vs. excluded,
revision policy, payment terms, and sign-off section.
```

### 26. Client Onboarding Email
```
Write a welcome email for a new freelance client. Include:
thank them, outline next steps (3-5 items), request access/
materials needed, set expectations for communication, and
share your availability. Warm and professional.
```

### 27. Upwork Profile Bio
```
Write an Upwork profile description for a [SERVICE TYPE]
freelancer. Include: a strong opening hook, 3 key skills,
types of projects you handle, your process in 3 steps,
and a CTA. Use keywords that clients search for.
300 words max.
```

### 28. Client Update Email (Weekly)
```
Write a template for weekly client updates. Include:
what was completed this week, what's in progress, any
blockers or decisions needed, next week's plan. Keep it
structured and scannable. Under 200 words.
```

### 29. Testimonial Follow-Up
```
Write a follow-up message to a client after project
completion. Thank them, summarize results achieved,
ask for a testimonial (with guiding questions), ask
for referrals, and mention availability for future work.
```

### 30. Service Packages Description
```
Create descriptions for 3 [SERVICE] packages:
Basic ($[X]), Standard ($[Y]), Premium ($[Z]).
For each: name, price, what's included (bullet list),
ideal for (who should choose this), delivery time.
Highlight the Standard as "Most Popular."
```

## DIGITAL PRODUCTS (Prompts 31-40)

### 31. eBook Outline
```
Create a detailed outline for an eBook titled "[TITLE]"
for [AUDIENCE]. Include: table of contents (8-10 chapters),
3-5 subsections per chapter with brief descriptions,
introduction hook, and conclusion CTA. Make it actionable,
not theoretical.
```

### 32. Online Course Curriculum
```
Design a course curriculum for "[COURSE TITLE]" targeting
[AUDIENCE]. Include: 5-7 modules, 3-5 lessons per module,
lesson descriptions, learning objectives, and suggested
exercises/assignments. Progressive difficulty.
```

### 33. Lead Magnet
```
Create a lead magnet titled "[TITLE]" for [AUDIENCE].
Format: [checklist/cheat sheet/template/guide]. Include
the full content — make it genuinely useful so readers
want to buy the full product. 1-2 pages max.
```

### 34. Product Launch Email Sequence
```
Write a 7-email product launch sequence for [PRODUCT]
priced at [$PRICE]. Emails: 1) announcement/teaser,
2) the story behind it, 3) what's inside, 4) social proof,
5) FAQ/objections, 6) launch day, 7) last chance.
Subject lines + body for each.
```

### 35. Gumroad Product Listing
```
Write a Gumroad product listing for [PRODUCT NAME].
Include: compelling title, description (300 words),
what's included (bullet list), who it's for, 3 preview
images descriptions, pricing justification, and a FAQ.
```

### 36. Webinar Script
```
Write a 45-minute webinar script for "[TITLE]" to sell
[PRODUCT] at the end. Structure: 5 min intro/hook,
25 min content (3 teaching segments), 10 min pitch,
5 min Q&A. Include slide suggestions. Teach genuinely
but create desire for the full product.
```

### 37. Affiliate Partner Outreach
```
Write an email to potential affiliates for [PRODUCT].
Include: what the product is, commission structure (50%),
conversion rate, average earnings per referral, and
what support you provide (swipe copy, graphics).
150 words.
```

### 38. Product Review Request
```
Write an email to [INFLUENCER TYPE] asking them to review
[PRODUCT]. Offer: free access, affiliate commission, or
collaboration. Be genuine, not pushy. Reference their
specific content to show you know their work.
```

### 39. Bundle Product Description
```
Write a description for a bundle containing [PRODUCTS].
Show the individual value vs bundle price (savings).
Include: what each product covers, who the bundle is for,
and why getting them together is better than separately.
```

### 40. Thank You / Onboarding Email
```
Write a post-purchase email for [PRODUCT]. Include:
thank them, confirm what they got, quick-start guide
(3 steps to get value immediately), support contact,
and ask them to share/review if they like it.
```

## BUSINESS & STRATEGY (Prompts 41-50)

### 41. Business Plan One-Pager
```
Create a one-page business plan for [BUSINESS IDEA].
Include: problem, solution, target market, revenue model,
competitive advantage, key metrics to track, and
first 90-day milestones. Keep each section to 2-3 sentences.
```

### 42. Competitor Analysis
```
Analyze 3 competitors in the [NICHE] space: [COMPETITOR 1],
[COMPETITOR 2], [COMPETITOR 3]. For each: pricing, strengths,
weaknesses, unique selling point. Then summarize how I can
differentiate. Present as a comparison table.
```

### 43. Brand Voice Guide
```
Create a brand voice guide for [BRAND/BUSINESS]. Include:
brand personality (3 adjectives), tone guidelines (formal
vs casual), vocabulary do's and don'ts, example sentences
in-voice and out-of-voice, and social media voice by
platform.
```

### 44. Content Strategy
```
Create a 90-day content strategy for [BUSINESS/BRAND]
targeting [AUDIENCE]. Include: content pillars (4-5 themes),
posting frequency by platform, content types and ratios,
growth tactics, and KPIs to track weekly.
```

### 45. SWOT Analysis
```
Perform a SWOT analysis for [BUSINESS/PRODUCT]. List
5 items each for Strengths, Weaknesses, Opportunities,
and Threats. For each item, include a brief explanation
and one actionable recommendation.
```

### 46. Customer Avatar
```
Create a detailed customer avatar for [PRODUCT/BUSINESS].
Include: demographics, psychographics, goals, frustrations,
buying triggers, objections, where they hang out online,
what influencers they follow, and their typical day.
```

### 47. Pricing Strategy
```
Help me set pricing for [PRODUCT/SERVICE]. Consider:
competitor pricing ([LIST COMPETITORS AND PRICES]),
my costs, perceived value, and target audience income.
Recommend a pricing strategy (value-based, competitive,
or penetration) with justification. Suggest 3 price points.
```

### 48. Partnership Pitch
```
Write a partnership pitch email to [COMPANY/PERSON] from
[MY BUSINESS]. Propose a collaboration that benefits both
parties. Be specific about what we bring to the table and
what we're asking for. Include potential ROI for them.
200 words.
```

### 49. Monthly Performance Review
```
Create a monthly business review template. Sections:
revenue vs target, top traffic sources, best-performing
content, customer feedback summary, what worked,
what didn't, and 3 priorities for next month.
```

### 50. 90-Day Goal Setting
```
Help me set 90-day goals for my [BUSINESS TYPE] business.
Include: 1 revenue goal (with daily/weekly breakdown),
1 audience growth goal, 1 product/skill development goal.
For each: the goal, why it matters, weekly milestones,
and daily actions needed.
```

## Getting the Most Out of These Prompts

1. **Don't use them verbatim** — customize heavily for your niche
2. **Iterate** — run the prompt, then say "make it more [specific/casual/urgent]"
3. **Combine prompts** — use the outline prompt, then the writing prompt for each section
4. **Build a swipe file** — save your best AI outputs for reference
5. **Add your voice** — AI gives you the draft, you add the personality
